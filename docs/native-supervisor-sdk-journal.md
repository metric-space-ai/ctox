# Original Supervisor SDK journal

The existing guarded Source method accepts `sdk_observe` only from its actual enrolled peer and retained original controller. The request includes offer_id, controller_id and one SourceSdkObservation v1. Fixtures generate native and browser types together. An observation cannot contain model/tool/control fields, a reply, credentials, authority, an actual flag or a terminated claim.

The private Workjet service journal maps its captured SDK callbacks to snake_case wire field names. Kind names remain child-spawned, child-closed, sdk-init, turn-submitted, parent-assistant, sdk-result, sdk-stream-joined and sdk-query-close-returned. Sequence begins at zero and is limited to 511. Each record is at most 4096 bytes. The same sequence with identical bytes replays its acknowledgement; changed replays and gaps fail. Records are committed under the same original Core/Policy controller reservation. No second lease, controller or writer is constructed.

Only the actual SDK spawn callback supplies child-spawned.pid. Child-closed comes from that captured ChildProcess object's close event, including stdio closure. SDK init/session, parent assistant message.id/model/uuid and result UUID come from the actual SDK iterator. turn-submitted is the adapter's original control correlation, not a provider UUID. Subagent messages cannot supply parent observations. The successful SDK query.close and joined stream consumer are separate callbacks. A custom query or a generic effect report must not feed this private journal.

The state machine requires the same session/turn and rejects replacement init, uncaptured or duplicate child close, post-result parent events and missing fields. Successful drain needs a nonempty captured child set, all observed closes, both stream/query callbacks and a successful SDK result. These metadata alone are not a native model witness: a future result assembler must join the parent message ID/model and SDK session to the native successful Messages observation and derive reply text from native upstream bytes. This draft retains execution_ready:false and does not populate actual_json or activate selected/default execution.

Tests use synthetic callbacks solely as isolated regression input. Model strings reused by the state-machine regression were verified in the historical authenticated catalog receipt from 09 Oct; they are not new runtime defaults, configuration or installed model evidence.
