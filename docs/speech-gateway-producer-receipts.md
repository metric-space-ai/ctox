# Native speech producer receipts

The speech gateway exposes an in-process provenance boundary for the native
Jour fixe adapter. Wire DTOs are data: `TranscriptEvent` may be deserialized and
its `Final` variant alone must never authorize speech transcript persistence.

Open a real `SpeechGateway::open_transcription(PcmFormat { sample_rate_hz: 16000 })`.
Bind `TranscriptionStream::stream_id()` to the current verified native meeting
before accepting PCM. This ID is generated by the server after the runtime or
provider handshake; it is not supplied by a browser. Consume
`next_verified_event()` on that same stream:

- `VerifiedTranscriptEvent::Partial` carries the stream ID, sequence and text
  delta. Accumulate ordered deltas within that stream for the transient UI.
- `VerifiedTranscriptEvent::Final(VerifiedTranscriptFinal)` carries private
  fields, has no constructor or Deserialize implementation, and exposes
  `stream_id()`, `sequence()`, `text()`, `model()`, `finish_to_final_ms()` and
  `audio_duration_ms()` as read-only getters. Only consuming the actual private
  gateway result channel can mint it. Events are consumed once.

`SpeechGateway::synthesize_verified(&SpeechRequest)` similarly invokes the
configured synthesis adapter and returns a private `VerifiedSpeechOutput`.
Its getters are `run_id()`, `text_sha256()`, `audio_sha256()`, `audio()`,
`format()`, `model()`, `input_characters()` and `elapsed_ms()`. SHA256 covers
the exact request UTF-8 and returned audio bytes. The run ID is server generated.
No constructor, Deserialize implementation or raw public output field exists.

These receipts establish producer provenance, not speaker identity, meeting
permission, audio intelligibility, playback readiness or installed acceptance.
The meeting consumer checks current native peer/session/collection permission
and the same Owner/project/meeting/Supervisor/deck/live binding before every
operation and after awaits. Its stream ledger must require that the receipt's
stream ID was opened under that same binding. A receipt from another meeting
must not be accepted. The consumer validates audio playability and duration,
stores bytes through the existing authorized native file/chunk store, and only
then publishes a narration reference. Transcript idempotency uses stream ID and
final sequence; the Owner-text endpoint cannot forge speech provenance.

PCM stays signed16LE mono16k, bounded to100ms chunks. Full queues return explicit
Backpressure. Native/local transcript utterances are bounded to15s. Cancel or
Drop aborts the sole stream task/socket; capture tracks and blob URLs belong to
the UI adapter and must be released on leave, scope change or terminal/review
transition. `finish_to_final_ms` starts at the gateway caller's finish mark;
producer capture, network and VAD delays require separate end-to-end measurement.

The backwards-compatible `next_event` and `synthesize` methods remain available
for diagnostics and other existing callers. They do not mint meeting receipts.
There is no new network endpoint, permission grant, environment switch or
provider account in this slice. Remote GPU routing, the meeting consumer and
installed microphone/audio measurements remain separate delivery obligations.
